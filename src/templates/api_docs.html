Organizer Operations

Requires an authenticated session belonging to the event organizer or global admin.

GET /api/export.csv
T2 Acceptance Route

Exports judging results, normalized scores, criteria breakdowns, and winner placements as a CSV file.

curl -X GET "{{ base_url }}/api/export.csv" \
  -H "{{ active_cookie or 'Cookie: session=' }}"
import requests

url = "{{ base_url }}/api/export.csv"
headers = {"Cookie": "{{ active_cookie or 'session=' }}"}
response = requests.get(url, headers=headers)
print("Status:", response.status_code)
print("CSV Preview:\n", response.text[:300])
const res = await fetch("{{ base_url }}/api/export.csv", {
  headers: { "Cookie": "{{ active_cookie or 'session=' }}" }
});
const csvText = await res.text();
console.log(csvText);
import java.net.http.*;
import java.net.URI;

HttpClient client = HttpClient.newHttpClient();
HttpRequest request = HttpRequest.newBuilder()
    .uri(URI.create("{{ base_url }}/api/export.csv"))
    .header("Cookie", "{{ active_cookie or 'session=' }}")
    .GET()
    .build();
HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
System.out.println(response.body());

Judge Operations & Isolation

Judges can only inspect their own evaluations. Backend enforces strict Role Isolation: accessing another judge's scores triggers HTTP 403 Forbidden.

Participant Operations & Community Voting

Participants can submit projects, participate in peer community voting, and engage in threaded project comments.

POST /projects/new
T1 Acceptance Route

Submits or drafts a project. Note: If submissions_close has passed, returns HTTP 4xx.

curl -X POST "{{ base_url }}/projects/new" \
  -H "Content-Type: application/json" \
  -H "{{ active_cookie or 'Cookie: session=' }}" \
  -d '{"title": "My Hackathon Project", "summary": "Fast lightweight platform", "repo_url": "https://github.com/..."}'
import requests

payload = {"title": "AI Assistant", "summary": "Next-gen copilot", "repo_url": "https://github.com/example/ai"}
res = requests.post("{{ base_url }}/projects/new", json=payload, headers={"Cookie": "{{ active_cookie or 'session=' }}"})
print("Status:", res.status_code)
const res = await fetch("{{ base_url }}/projects/new", {
  method: "POST",
  headers: { "Content-Type": "application/json", "Cookie": "{{ active_cookie or 'session=' }}" },
  body: JSON.stringify({ title: "My Hackathon Project", summary: "Demo" })
});
String body = "{\"title\":\"My Project\",\"summary\":\"Demo Writeup\"}";
HttpRequest req = HttpRequest.newBuilder()
    .uri(URI.create("{{ base_url }}/projects/new"))
    .header("Content-Type", "application/json")
    .header("Cookie", "{{ active_cookie or 'session=' }}")
    .POST(HttpRequest.BodyPublishers.ofString(body)).build();
HttpResponse<String> res = HttpClient.newHttpClient().send(req, HttpResponse.BodyHandlers.ofString());

Webhooks & Event Subscriptions

HackForge dispatches real-time HTTP POST notifications with HMAC-SHA256 cryptographic signature verification.

POST /api/events/{event_id}/webhooks

Registers a target URL and receives a unique whsec_... secret for signature verification.

curl -X POST "{{ base_url }}/api/events/{{ event.id }}/webhooks" \
  -H "Content-Type: application/json" \
  -H "{{ active_cookie or 'Cookie: session=' }}" \
  -d '{"target_url": "https://api.yourdomain.com/webhook", "events": "project.submitted,results.published"}'
import requests

payload = {"target_url": "https://my-app.com/webhook", "events": "project.submitted,results.published"}
sub = requests.post("{{ base_url }}/api/events/{{ event.id }}/webhooks", json=payload, headers={"Cookie": "{{ active_cookie or 'session=' }}"}).json()
print("Secret:", sub["secret"])
const res = await fetch("{{ base_url }}/api/events/{{ event.id }}/webhooks", {
  method: "POST",
  headers: { "Content-Type": "application/json", "Cookie": "{{ active_cookie or 'session=' }}" },
  body: JSON.stringify({ target_url: "https://my-app.com/webhook", events: "project.submitted" })
});
String body = "{\"target_url\":\"https://my-app.com/webhook\",\"events\":\"project.submitted\"}";
HttpRequest req = HttpRequest.newBuilder()
    .uri(URI.create("{{ base_url }}/api/events/{{ event.id }}/webhooks"))
    .header("Content-Type", "application/json")
    .header("Cookie", "{{ active_cookie or 'session=' }}")
    .POST(HttpRequest.BodyPublishers.ofString(body)).build();
HttpResponse<String> res = HttpClient.newHttpClient().send(req, HttpResponse.BodyHandlers.ofString());
